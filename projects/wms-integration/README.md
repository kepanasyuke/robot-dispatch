# wms-integration

Интеграция с системой заказчика (WMS): устойчивый HTTP-клиент, синхронизация заказов в задачи
диспетчера и приём входящих вебхуков с проверкой подписи.

## Зачем

Интеграции падают не «вообще», а конкретными способами: заказчик отдаёт 503 на секунду, WMS
уходит на ночное обслуживание, сеть рвёт соединение, вебхук приходит дважды. Сервис закрывает
именно эти сценарии.

## Что внутри

### Устойчивый клиент (`client.py`)

* **Повторы** на `timeout`, `429` и `5xx`: до 3 попыток, экспоненциальный backoff с потолком и
  джиттером, `Idempotency-Key` **сохраняется между попытками** — иначе повтор создаст второй заказ.
* **4xx не повторяется**: запрос неверный, а сервис заказчика жив. Брейкер при этом считает вызов
  успешным — иначе валидационные ошибки открывают предохранитель.
* **Circuit breaker** (`circuit.py`): после N подряд отказов трафик останавливается на
  `reset_timeout`, затем пропускается один пробный запрос (half-open). Успех закрывает цепь,
  ошибка — снова открывает.
* **Явные ошибки**: `HttpRequestError` (со `status_code` и числом попыток) и `CircuitOpenError`
  (с `retry_after`).

### Синхронизация заказов (`orders.py`)

Заказ WMS → задача диспетчера. `external_id = "wms:<order_id>"` делает повторную синхронизацию
идемпотентной: диспетчер вернёт `200` вместо `201`, а `SyncResult.created` покажет, создана задача
или это реплей. Ошибки маппинга (`destination` пустой, `items < 1`, `priority` вне `0..1000`)
ловятся до запроса.

### Вебхуки (`webhooks.py`)

`POST /webhooks/wms/order` защищён тремя проверками:

1. HMAC-SHA256 по `timestamp.body` (constant-time сравнение);
2. окно допуска по времени (по умолчанию ±5 минут);
3. защита от повторов: та же подпись второй раз → `409`.

Без третьего пункта перехваченный запрос можно воспроизвести сколько угодно раз.

## Проверка

```bash
python scripts/dev.py test projects/wms-integration
python scripts/dev.py lint
```

Тесты используют `httpx.MockTransport`: сценарии (503 → успех, таймаут, открытая цепь, half-open,
replay вебхука) воспроизводятся детерминированно и без сети.
