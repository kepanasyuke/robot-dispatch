Правило: заказ, потерянный роботом, возвращается в очередь — до 3 попыток, затем −1 жизнь. Заказ, который никто не взял, сгорает сразу.

Клик по заказу — ближайший свободный робот. 123 — отправить выбранному роботу, пробел — пауза, R — заново.
